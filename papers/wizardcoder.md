## Why It Matters

Applied Evol-Instruct — iteratively making code instructions harder — to fine-tune StarCoder into a model that surpassed GPT-3.5 on HumanEval. Showed that clever synthetic data generation can close the gap with models 10x larger. A key early demonstration that instruction quality matters more than model size for code tasks.
