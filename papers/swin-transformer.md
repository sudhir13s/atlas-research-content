## Why It Matters

Introduced shifted windows to create a hierarchical vision transformer that produces multi-scale feature maps — something the original ViT could not do. This makes it suitable for dense prediction tasks like object detection and semantic segmentation. Became the dominant backbone for detection and segmentation, bridging the gap between ViT and CNN-based architectures.
