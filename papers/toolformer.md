## Why It Matters

Trained a language model to autonomously decide when and how to call external tools — calculator, search engine, translator — by inserting API calls into its own text generation. No human annotations of tool use needed; the model learns from self-play. Established the paradigm that LLMs should be trained to use tools natively rather than being prompted to do so.
