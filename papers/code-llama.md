## Why It Matters

Specialized Llama 2 for code by continued pretraining on 500B code tokens, adding fill-in-the-middle capability and extending context to 100K tokens. Available at 7B/13B/34B sizes, making it practical for local IDE integration. Proved that domain-specific continued pretraining is more efficient than training a code model from scratch.
