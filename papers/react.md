## Why It Matters

Interleaved chain-of-thought reasoning with tool actions in an observation-thought-action loop, allowing LLMs to plan, execute, and adapt. Outperformed both pure reasoning and pure acting approaches. The ReAct pattern is now the default agent architecture — virtually every LLM agent framework implements some version of this thought-action-observation cycle.
