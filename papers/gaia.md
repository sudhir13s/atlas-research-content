## Why It Matters

Created a benchmark of 466 real-world questions requiring multi-step reasoning, web browsing, file manipulation, and tool use that humans can solve but current AI agents mostly cannot. Unlike synthetic benchmarks, GAIA tests the full agent loop on tasks grounded in reality. The definitive measure of whether an AI agent can actually function as a general assistant.
