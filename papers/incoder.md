## Why It Matters

Trained a code model with a causal masking objective that supports both left-to-right generation and fill-in-the-middle completion. This bidirectional capability is essential for IDE autocomplete where the cursor is in the middle of existing code. Influenced the infilling capabilities now standard in Copilot and every code assistant.
