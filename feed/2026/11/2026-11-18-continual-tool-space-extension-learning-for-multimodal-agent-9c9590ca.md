## Summary

This work introduces COTEX, a continual tool-space extension learning method for multimodal agents that adds new specialist tools at efficient adapter-level cost. It uses specific parameter directions for triggering tool calls and choosing tools, applying orthogonal constraints to leave earlier tool choices unaffected. Experiments on two agents and three specialist tools show gains across ten vision-language benchmarks with minimal drops on existing tools.
